# 小夜的温暖小窝 v3 模块化版

一个温馨的个人网页应用，包含音乐播放器、日记本、记忆库、创作空间等功能。

## 功能特性

### 🎵 音乐播放器
- 本地音乐播放
- 播放列表管理
- 播放控制（播放/暂停/上一首/下一首）
- 音量调节
- 播放进度显示

### 📝 日记本
- 富文本编辑器
- 日记分类管理
- 时间线视图
- 本地存储

### 🧠 记忆库
- 重要记忆记录
- 分类整理
- 快速检索
- 长期存储

### ✨ 创作空间
- 富文本编辑器（支持图文）
- 文章/感悟/经验/作品分类
- 标签系统
- 评论功能（小夜可以评论）
- 本地存储

### 🎭 悬浮播放器
- 小夜动画角色
- 根据应用活动切换动画
  - 音乐播放器 → 工作中动画
  - 日记/记忆/创作 → 学习中动画
  - 其他 → 闲置动画
- 淡入淡出过渡效果

## 部署说明

### GitHub Pages 部署
1. 将整个文件夹上传到GitHub仓库
2. 进入仓库 Settings → Pages
3. 选择 Source: Deploy from a branch
4. 选择 Branch: main, Folder: / (root)
5. 保存后等待部署完成

### 本地运行
直接打开 `index.html` 即可运行

## 文件结构
```
├── index.html          # 主页面
├── style.css          # 样式文件
├── core.js            # 核心功能
├── music-player.js    # 音乐播放器
├── diary-app.js       # 日记本应用
├── memory-system.js   # 记忆库系统
├── creation-space.js  # 创作空间
├── about-page.js      # 关于页面
├── welcome-page.js    # 欢迎页面
├── assets/            # 资源文件
│   ├── *.png         # 图标图片
│   └── *.mp4         # 动画视频
└── README.md         # 说明文档
```

## 技术栈
- HTML5
- CSS3 (Flexbox, Grid)
- JavaScript (ES6+)
- localStorage 数据存储
- 原生浏览器API

## 注意事项
1. 音乐文件需要放置在 `music/` 文件夹中
2. 动画视频文件需要三个：idle.mp4, working.mp4, studying.mp4
3. 所有数据存储在浏览器localStorage中
4. 插入图片需要使用在线图片URL
