🔧 测试欢迎窗口不唤醒修复

✅ 修复已应用
// core.js - openApp函数修改 if (appName !== 'welcome') { const appOpenedEvent = new CustomEvent('appOpened', { detail: { appName } }); document.dispatchEvent(appOpenedEvent); }
// core.js - 事件监听修改 const isWelcomeWindow = event.detail?.appName === 'welcome'; if (!isWelcomeWindow) { isSleeping = false; // 唤醒小夜 }

修复说明：

问题原因：openApp函数会立即触发appOpened事件，标记设置可能来不及生效。

解决方案：在openApp函数内部直接判断，如果是欢迎窗口就不触发事件。

双重保障：事件监听也检查应用名，确保欢迎窗口不会唤醒小夜。

预期效果：

  • 网页打开 → 小夜睡觉 + 欢迎窗口弹出
  • 小夜继续睡觉，不会被唤醒
  • 需要手动点击或打开其他应用才能唤醒
